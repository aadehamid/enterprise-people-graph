Intentional Arrangement
Ontology Pipeline Resource Catalog
Resources from Ontology Pipeline, A framework for building knowledge infrastructures
Jessica Talisman, MLS
Oct 18, 2026
This list collects the standards, vocabularies, tools and readings behind The Ontology Pipeline, the book’s resource list merged with everything the Intentional Arrangement essays have cited. It is ordered according to the sequence presented by the Ontology Pipeline, standards first (of course), then the guidelines for constructing vocabularies, the metadata schemas those vocabularies populate, published vocabularies you can reuse, the registries and standards bodies that govern them, tools, and sources.

Each entry includes what it is, then where to find it.

W3C standards
RDF is the data model; RDFS, SKOS and OWL are vocabularies built upon it in increasing order of expressivity.

The data model
RDF 1.2 Concepts and Abstract Data Model — the current specification of triples, graphs, IRIs, literals and datasets; Candidate Recommendation, 2026. w3.org/TR/rdf12-concepts

RDF 1.2 Primer — the readable introduction to the model. w3.org/TR/rdf12-primer

RDF 1.2 Semantics — the formal semantics behind entailment. w3.org/TR/rdf12-semantics

RDF 1.1 Concepts, Primer and Semantics — the 2014 Recommendations that most tools still implement. w3.org/TR/rdf11-concepts, w3.org/TR/rdf11-primer, w3.org/TR/rdf11-mt

RDF Model and Syntax Specification (1999) — the original Recommendation, Lassila and Swick. w3.org/TR/1999/REC-rdf-syntax-19990222

RDF-star — triple terms, statements about statements; a Community Group report now folded into RDF 1.2. w3.org/TR/rdf12-concepts

RDF Dataset Canonicalization (RDFC-1.0) — a deterministic form for signing and comparing graphs, 2024. w3.org/TR/rdf-canon

Vocabularies built on RDF
RDF Schema 1.2 and 1.1 — classes, subclasses, properties, domain and range. w3.org/TR/rdf12-schema, w3.org/TR/rdf-schema

SKOS, Simple Knowledge Organization System Reference — concepts, labels, broader, narrower, related, mapping relations; the vocabulary for controlled vocabularies, taxonomies and thesauri. w3.org/TR/skos-reference

SKOS-XL — labels as resources, so a label can carry its own properties and history. w3.org/TR/skos-reference/skos-xl.html

OWL 2 Web Ontology Language — the Primer, the Document Overview and the Profiles (EL, QL, RL). w3.org/TR/owl2-primer, w3.org/TR/owl2-overview, w3.org/TR/owl2-profiles

PROV-O, the Provenance Ontology — entities, activities and agents; wasGeneratedBy, wasAttributedTo, wasDerivedFrom. w3.org/TR/prov-o

OWL-Time — temporal entities, instants, intervals and durations. w3.org/2006/time

DCAT, Data Catalog Vocabulary — describing datasets, distributions and catalogs. w3.org/ns/dcat

DCMI Metadata Terms — Dublin Core as an RDF vocabulary, the dcterms namespace. dublincore.org/specifications/dublin-core/dcmi-terms

RDF Data Cube Vocabulary — multidimensional statistical data, compatible with SDMX. w3.org/TR/vocab-data-cube

P-Plan — plans, steps and variables, an extension of PROV. purl.org/net/p-plan

Serializations
Turtle — the human-readable syntax, RDF 1.2 and 1.1. w3.org/TR/rdf12-turtle, w3.org/TR/turtle

N-Triples — one triple per line, for streaming, diffing and bulk loading. w3.org/TR/rdf12-n-triples, w3.org/TR/n-triples

N-Quads — N-Triples with a fourth column for the graph name, for datasets. w3.org/TR/rdf12-n-quads, w3.org/TR/n-quads

TriG — Turtle extended to named graphs. w3.org/TR/rdf12-trig, w3.org/TR/trig

RDF/XML — the original XML syntax from 1999. w3.org/TR/rdf12-xml, w3.org/TR/rdf-syntax-grammar

JSON-LD 1.1 — RDF as JSON; the syntax Schema.org markup and most web APIs use. w3.org/TR/json-ld11

RDFa Core 1.1 — RDF carried in the attributes of HTML and XML documents. w3.org/TR/rdfa-core

Notation3 (N3) — the rules-capable superset of Turtle; W3C Team Submission, maintained by the N3 Community Group. w3.org/TeamSubmission/n3

RDF/JSON — the RDF 1.1 JSON Alternate Serialization, a plain JSON mapping; W3C Working Group Note. w3.org/TR/rdf-json

TriX — triples in XML with named graphs; W3C member submission, still read by Jena and RDF4J. w3.org/2004/03/trix

Microdata to RDF — how HTML5 microdata maps onto RDF; W3C Note. w3.org/TR/microdata-rdf

CSV on the Web (CSVW) — the W3C model for describing tabular data so it converts to RDF. w3.org/TR/tabular-data-model

RDF-star syntaxes — Turtle-star, TriG-star, N-Triples-star and SPARQL-star from the 2021 Community Group report, now folded into the RDF 1.2 editions as triple terms. w3c.github.io/rdf-star

HDT, Header-Dictionary-Triples — compressed, queryable binary RDF; W3C member submission. rdfhdt.org

Jelly — binary serialization and streaming protocol for RDF, built for high-throughput pipelines. w3id.org/jelly

RDF Binary (Thrift and Protobuf) — Apache Jena’s binary encodings for fast exchange between Jena systems. jena.apache.org/documentation/io/rdf-binary.html

OWL Functional Syntax and OWL Manchester Syntax — the two non-RDF syntaxes for OWL 2 ontologies, used by Protégé and the OWL API. w3.org/TR/owl2-syntax, w3.org/TR/owl2-manchester-syntax

Query and validation
SPARQL 1.2 Query and Update — the current specifications. w3.org/TR/sparql12-query, w3.org/TR/sparql12-update

SPARQL 1.1 Query Language — the 2013 Recommendation. w3.org/TR/sparql11-query

SHACL, Shapes Constraint Language — closed-world validation of RDF against shapes. w3.org/TR/shacl

W3C RDF Validator — syntax checking as a service. w3.org/RDF/Validator

SKOS extensions and mapping standards
Where SKOS stops, these pick up: statistical classifications, ISO thesaurus features, lexical detail and mappings between vocabularies.

XKOS, Extended Knowledge Organization System — the DDI Alliance’s SKOS extension for statistical classifications, with correspondence tables between versions. rdf-vocabulary.ddialliance.org/xkos, best practices at linked-statistics.github.io/xkos

SKOS-Thes (ISO-THES) — the vocabulary that maps ISO 25964 thesaurus features onto SKOS. dublincore.org/specifications/skos-thes/ns

UNESKOS — the UNESCO Thesaurus extension, adding the inverse of skos:inScheme. skos.um.es/TR/uneskos

OntoLex-Lemon, Lexicon Model for Ontologies — lexical entries, forms and senses attached to ontology terms; W3C Community Group report, 2016. w3.org/2016/05/ontolex

SSSOM, Simple Standard for Sharing Ontological Mappings — a tabular standard for exchanging mappings with provenance. mapping-commons.github.io/sssom

ADMS, Asset Description Metadata Schema — the Interoperable Europe profile for publishing controlled vocabularies in SKOS. interoperable-europe.ec.europa.eu

DCAT-AP — the European application profile of DCAT. semiceu.github.io/DCAT-AP

Linked Open Vocabularies entries for SKOS and SKOS-XL — usage statistics and dependencies across the LOD cloud. lov.linkeddata.es/dataset/lov/vocabs/skos, lov.linkeddata.es/dataset/lov/vocabs/skosxl

Linked open data sources
Datasets published as RDF with dereferenceable URIs and, in most cases, a public SPARQL endpoint. These are the reconciliation targets: the identifiers your own vocabulary maps to with skos:exactMatch and skos:closeMatch.

Wikidata — 100 million items, multilingual labels, the Wikidata Query Service. wikidata.org, endpoint query.wikidata.org

DBpedia — the knowledge graph extracted from Wikipedia; ontology of 685 classes, 50 million interlinks across the LOD cloud. dbpedia.org, endpoint dbpedia.org/sparql

YAGO — Wikidata cleaned against Schema.org, with logical constraints. yago-knowledge.org

BabelNet — multilingual lexical-semantic network linking WordNet and Wikipedia. babelnet.org

Getty Vocabularies as Linked Open Data — AAT, TGN, ULAN and CONA with a SPARQL endpoint. vocab.getty.edu

Library of Congress Linked Data Service — LCSH, LC Name Authority File, LC Classification, genre/form terms and the ISO vocabularies, all dereferenceable. id.loc.gov

VIAF, Virtual International Authority File — name authorities from national libraries clustered into one file. viaf.org

ISNI, International Standard Name Identifier — persistent public identifiers for people and organizations. isni.org

OCLC FAST — faceted subject terms derived from LCSH, as linked data. fast.oclc.org

WorldCat Entities — OCLC’s linked-data identifiers for works, persons and places. id.oclc.org/worldcat/entity

GND, Gemeinsame Normdatei — the German National Library’s integrated authority file, in RDF. d-nb.info/standards/elementset/gnd

data.bnf.fr — the Bibliothèque nationale de France’s authorities and RAMEAU as linked data. data.bnf.fr

Europeana — cultural heritage aggregated under the Europeana Data Model, with a SPARQL endpoint. pro.europeana.eu/page/linked-open-data

GeoNames — eleven million place names with RDF descriptions. geonames.org/ontology

Pleiades — gazetteer of ancient places, linked data. pleiades.stoa.org

EU Vocabularies — EuroVoc and the authority tables of the Publications Office, with the CELLAR SPARQL endpoint. op.europa.eu/en/web/eu-vocabularies, endpoint publications.europa.eu/webapi/rdf/sparql

AGROVOC — FAO’s thesaurus as linked data, SKOS-XL, with SPARQL. agrovoc.fao.org/sparql

UNESCO Thesaurus — published as SKOS with a Skosmos browser and endpoint. vocabularies.unesco.org

MeSH RDF — the Medical Subject Headings as linked data, with SPARQL. id.nlm.nih.gov/mesh

BioPortal — the biomedical ontology repository, SPARQL over 1,000-plus ontologies. bioportal.bioontology.org, endpoint sparql.bioontology.org

OBO Foundry — the coordinated biological and biomedical ontologies, each with PURLs. obofoundry.org

UniProt — protein sequence and function data with one of the largest public SPARQL endpoints. sparql.uniprot.org

Bio2RDF — life-science databases converted to linked data. bio2rdf.org

FIBO, Financial Industry Business Ontology — the EDM Council’s OWL ontology, published with dereferenceable IRIs. spec.edmcouncil.org/fibo

ORCID and ROR — persistent identifiers for researchers and research organizations. orcid.org, ror.org

OpenCitations — open citation data as RDF, with SPARQL. opencitations.net

Data Commons (Google) — public statistical data unified under a Schema.org-based graph. datacommons.org

Linked Open Vocabularies (LOV) — the registry of the RDF vocabularies these datasets use. lov.linkeddata.es

Linked Open Data Cloud — the diagram and dataset registry of the whole. lod-cloud.net

Construction guidelines and standards
Two documents govern every controlled vocabulary and thesaurus; the rest define the element sets and bibliographic models the metadata layer inherits.

Vocabulary and thesaurus construction
ANSI/NISO Z39.19-2005 (R2010), Guidelines for the Construction, Format, and Management of Monolingual Controlled Vocabularies — term selection, warrant, scope notes, reciprocity, displays. niso.org/publications/ansiniso-z3919-2005-r2010

ISO 25964-1, Thesauri for information retrieval — the international thesaurus standard, successor to ISO 2788 and 5964; a revision in draft names AI among the uses a thesaurus serves. iso.org/standard/53657.html

ISO 25964-2, Interoperability with other vocabularies — mapping practice between thesauri, classification schemes and taxonomies. iso.org/obp/ui/en/#iso:std:iso:25964:-2

NISO, ISO 25964 pages — schemas and committee material. niso.org/schemas/iso25964

Dublin Core as a standard
IETF RFC 2413, Dublin Core Metadata for Resource Discovery (1998) — the first specification of the fifteen elements. rfc-editor.org/rfc/rfc2413.txt

ANSI/NISO Z39.85-2012 and ISO 15836 — the Dublin Core element set as US and international standards. niso.org/publications/ansiniso-z3985-2012-dublin-core-metadata-element-set, iso.org/standard/71341.html

DCMI Application Profile Guidelines and Guidelines for Dublin Core Application Profiles — how to build a metadata application profile. dublincore.org/specifications/dublin-core/application-profile-guidelines, dublincore.org/specifications/dublin-core/profile-guidelines

DCMI Qualifiers and Usage Guide — element refinements and encoding schemes. dublincore.org/specifications/dublin-core/dcmes-qualifiers

NISO, Understanding Metadata (Riley, 2017) — the primer. niso.org/publications/understanding-metadata

W3CDTF, Date and Time Formats — the W3C profile of ISO 8601 that fixes how dates and times are written, from a bare year to a full timestamp with time zone; the encoding scheme Dublin Core and most metadata application profiles designate for date elements. w3.org/TR/NOTE-datetime

FAIR Guiding Principles — findable, accessible, interoperable, reusable. en.wikipedia.org/wiki/FAIR_data

A SKOS Taxonomy and Thesaurus Editor, Built from Standards
Intentional Arrangement is a SKOS taxonomy editor that opens as a single static page in your web browser. There is no account, server, or upload. You write concepts, labels, definitions, and relationships; the editor validates them as you type and exports the result to Turtle, RDF/XML, JSON-LD, RDF/JSON, CSV, Excel, and Markdown.

The Intentional Arrangement SKOS Editor is live at https://jesstalisman-ia.github.io/intentional-arrangement-skos/ and the source is public at https://github.com/jesstalisman-ia/intentional-arrangement-skos.




The Origin of the Editor

I built this inside a larger toolset I use for client vocabulary work, then pulled the SKOS portion out so folks could use it on its own. The working model follows W3C SKOS and SKOS-XL, Dublin Core for scheme metadata, and ISO 25964, the international standard for thesauri and interoperability with other vocabularies.




Every concept gets a URI, one preferred label per language, alternate and hidden labels, the full set of SKOS notes, and as many broader concepts as the vocabulary requires. Collections and ordered collections sit beside the hierarchy without being mistaken for it. Language tags follow BCP 47.

Validation inside the edit loop
Vocabulary problems get expensive once the vocabulary ships. The editor applies the qSKOS quality criteria (Mader, Haslhofer and Isaac, 2012) while you are still editing: orphan concepts, missing labels, cyclic hierarchies, and the rest of the checklist surface in the workspace, and most come with a one-click fix.

Work stays in your browser
Projects autosave to local browser storage. From there you can export, download a workspace backup, or generate a read-only share link that packs the whole taxonomy inside the URL for business reviewers. Teams whose vocabularies outgrow a URL can connect an optional Apache Jena Fuseki server and publish each project to its own named graph. Clearing browser data erases local work, so export regularly.




Keep the editorial judgment
The editor is for people anyone wanting to build a standards-based RDF controlled vocabulary, taxonomy, and thesaurus. Plain language queries use offline rules, and nothing in the browser editor calls a language model. An optional REST API handles validation and conversion for teams with their own pipelines, and an MCP server exposes the same functions to assistant tools.

The license with a size threshold
Organizations with fewer than 75 employees may use, modify, and redistribute the editor free under Apache 2.0 as modified by the size-based licensing notice. Organizations with 75 or more employees need a written enterprise license before use; inquiries go to Hello@ontologypipeline.com. The taxonomies you build are yours.

Several recent releases came directly from GitHub issues so feedback, feature requests, and use cases are greatly appreciated!
